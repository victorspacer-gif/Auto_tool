🏗 Architecture Comparison

TibiaAuto12 (Original)

  • Monolithic single-process GUI (tkinter)
  • Global EnabledCaveBot + ThreadManager for threading
  • CaveBotController — self-contained loop (walk → attack → loot)
  • Hardware-only input (SendToClient via pynput key simulation)
  • HookWindow — PrintWindow Win32 API for screen capture
  • All state in global variables + JSON files
  • 3 modules: CaveBot / Scanners / AutoLooter

Auto_tool (SystemMonitor)

  • Layered DI — container.py injects services into UI
  • ExecutionGate + MouseGate — FIFO input ownership (thread-safe)
  • 3 service split: CaveBotService / ChaseTargetService / AutoLooterService
  • Dual-mode InputRouter — hardware (pynput) OR direct (Win32 SendMessage)
  • ImageFinder — mss screen capture + OpenCV template matching
  • AppRuntime state object — typed dataclasses, not globals
  • 10+ services — integrated with healer, fishing, mana, etc.

⚡ Key Improvements in Auto_tool

AreaImprovementWhy It Matters
Mark dropdown Shows names ("CheckMark", "Star") instead of numbers (1–20) No mental mapping required — you see exactly what you're selecting
Live preview Updates in real-time as Mark or Type dropdown changes Immediate visual feedback when browsing options
Input safety ExecutionGate FIFO scheduler prevents input conflicts between modules CaveBot, ChaseTarget, AutoLooter, and AutoHealer can't click over each other
Dual input mode Hardware (physical cursor) OR Direct (background window injection) Background hunting works while user does other tasks
Human-like movement Bezier curves + jitter + variable speed Less detectable as automation (anti-cheat evasion)
Coordinate fallback If image detection fails 3 times, uses saved coordinates More reliable — doesn't get stuck in infinite image search loops
Arrival retry 3 quick + 5 slow retries with progressive patience Handles lag spikes without false "not arrived" assertions
Auto-start companions CaveBot auto-launches ChaseTarget and AutoLooter One-click start — no manual module enabling
Global pause/stop F5 for pause, HOME for emergency kill Instant shutdown from keyboard — no mouse to GUI needed
DI architecture Container + typed runtime state vs global variables Testable, debuggable, maintainable codebase
Modular tab UI Each module is a separate tab with responsive columns Clean separation — modules don't interfere with each other's UI state
Pixel tolerance pixel_matches_color() with configurable tolerance Works with game rendering variations (shadows, anti-aliasing)
