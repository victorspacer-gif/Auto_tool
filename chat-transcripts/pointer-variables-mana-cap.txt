--- IMPLEMENTATION SUMMARY ---

We completed the pointer-based reading system for HP, MP (Mana), and Cap (Max HP) stats. Here's what was built:

1. POINTER PROFILE MODULES
   - studiomemuer_hp_module/hp_profile.py  → HP at offset +0x4A0 (Byte/Double)
   - studiomemuer_mp_module/mp_profile.py  → MP at offset +0x4F8 (Double)
   - studiomemuer_cap_module/cap_profile.py → Cap at offset +0x4B8 (Double)

2. STATE MODEL (systool/models.py)
   Added pointer fields to CharStatusState:
   - hp_value, mp_value, cap_value          (current values)
   - hp_source, mp_source, cap_source       ("pointer" or "ocr")
   - hp_pointer_address_hex, mp_pointer_address_hex, cap_pointer_address_hex

3. SERVICES (systool/services.py)
   - HPService.get_hp()  → reads from memory via LightMemoryController
   - MPService.get_mp()  → reads from memory via LightMemoryController
   - CapService.get_cap() → reads from memory via LightMemoryController
   All services fall back to OCR if pointer reading fails.

4. UI (systool/app.py) — Variables Tab Layout:
   Left Column:
     📡 Live Values    → Level, HP, Cap, MP, Food
     🔗 Variable Names → Pointer chains with resolved hex addresses
   
   Right Column:
     📋 Source Metadata → HP/MP/Cap source + pointer addresses (hex)
     📊 Read Statistics → Regen rates, read counts, last update time

5. VARIABLE NAMES PANEL
   Shows the actual memory variable names for each stat:
   HP  → miracle_gl + 0xA783E0 + 0x4A0 = A78880 (Double)
   MP  → miracle_gl + 0xA783E0 + 0x4F8 = A788D8 (Double)
   Cap → miracle_gl + 0xA783E0 + 0x4B8 = A78898 (Double)
